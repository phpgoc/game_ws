# 娘娘升级

四人对家，1–2 副牌，所有牌发完，一副牌允许 14/14/13/13 张。第一场由房主（0 号位）主打，从 3 开始，两队分别保留自己的级数。

- 只能出同点数的任意张牌；跟牌必须张数相同且点数更大。没有顺子、带牌和炸弹，五张 2 压不了六张 3。
- 普通牌由小到大为 3、4、…、K、A、2。当前级牌仅次于小王、大王，不分花色。两副牌的物理 ID 为 1–108。
- 一方拿到第 1、2 名，主打方赢时升两级；第 1、3 名升一级；第 1、4 名不升级。同队前两名时直接结算，不虚构剩余名次。
- 非主打方赢，只换当前主打人的下家主打，新主打方不升级。两队级数各自保留。
- 无论哪一方赢，1、2 名下一局吃两贡，1、3 名吃一贡，1、4 名没有贡。下一局主打人（两贡时加对家）向各自上家收最大牌、还自己的最小牌。按下一局级牌比较，发牌后自动交换；同强度按物理 ID 决定，不另加抗贡。
- 主打方赢，由原主打人的对家接打；输了由原主打人的下家接打。接打者领牌。打 A 且 1、4 名时继续打 A；只有主打方在打 A 时拿到 1、2 或 1、3 名才赢整场，升到 A 本身不算获胜。
- 某人走完且无人盖过其最后一手时，仍持牌的对家接风；未走完的最大牌持有者继续领牌。
- 玩家可以不要；不能在空桌时不要。跳过已走完的座位。

## 运行

在公开 ws 工作区：

    cargo run -p niangniang -- --host 0.0.0.0 --port 9012

在主仓库启用官方准入和整场统计：

    cargo run -p niangniang@0.1.0-official.1 --features official -- --host 127.0.0.1 --port 9012

网页入口 /niangniang，可以选择官方服或输入自建 ws/wss 地址。使用统一浏览器 WebSocket / Tauri 原生传输。官方服务器支持添加 AI；默认托管能管就管，AI 托管使用公开记牌判断各张数的控制牌，结合上家、下家和对家接应决定抢牌、让牌与接风。第一名确定后优先争第二、第三。所有决策只使用自己的牌及公开状态，不共享 AI 队友的暗牌。

官方仅在整场结束后记录一次胜负；非官方服务器不连接账户、会员或统计服务。断线保留原座位并自动出牌，返回原房间可重连。主动离开中止整场，避免中途替换队友改变比赛身份。

Tauri 单游戏包可使用 --server niangniang，全部游戏包也包含本玩法。独立 Android 服务包装使用 -Pgame=niangniang，JNI 特性 niangniang；每个包只开启一个游戏。实际系统签名和商店发布使用项目现有流程。
